# 셋업 가설 v2 구현 경계

매매 권고가 아니다. 사용자가 제시한 후보 선정 규칙을 코드로 옮길 때의 명시적
가정과 미구현 데이터 경계를 기록한다. live/paper 주문 경로에는 연결하지 않았다.

## 구현한 순수 평가 규칙

`setup_screening.evaluate_setup()`은 최소 200개 일봉과 외부 context를 받아
다음을 결정적으로 평가한다.

- 눌림: `close > MA50 > MA200`, MA50 이격 `0%..4%`
- 과매도 반전: Wilder RSI14 `<=35`, 양봉, 전일 고가 돌파를 모두 요구
- 수급 전환: PIT가 보장된 최근 6개 연속 거래 세션으로 `이전 5일 외인
  순매수 합/거래대금 합 < 0`, `현재 5일 > 0`, 최신 세션 외인 순매수를 모두 요구
- 방어형 v1: 눌림 또는 확인형 RSI 반전 중 가격 setup 1개와 독립 수급 전환을
  모두 요구. 가격 setup 2개를 독립 증거 2개로 세지 않음
- 금지: RSI14 `>=70`, 당일 수익률 `<=-3%`, 손절선의 105% 이하, 물타기,
  이벤트 임박, 갭상승 추격
- 이벤트 달력과 갭 추격 검토가 입력되지 않으면 fail-closed
- 밸류 A 진단: 선행 EPS 성장 `>=25%`와 업종 내 PER percentile `<=30%`
- 밸류 C: 업종 상대 고평가 또는 순수 기술반등
- 나머지는 B. 절대 PBR/PER 숫자 하나로 티어를 올리지 않음

금지 필터가 하나라도 있거나 가격·수급 중 하나가 부족하면 승인하지 않는다.
수급은 명시적 `signal_session` 이내이면서 `available_at <= decision_at`인
레코드만 사용한다. `session_index`가 정확히 1씩 증가해야 하므로 주말·휴일은
허용하지만 전체 입력과 최종 eligible 6세션 양쪽에서 거래 세션 누락을 거부한다.
당일 확정치가 아직 없으면 마지막 가용
세션을 기준으로 이전 6세션을 사용한다. 일별 비율 평균이 아니라 5일 합산
순매수/5일 합산 거래대금을 써서 거래대금이 작은 하루가 과대 반영되지 않게 한다.
외인 전환은 1성, 기관까지 동시 확인되면 2성이다. 기관 여부는 승인·사이즈를
바꾸지 않는다.

밸류 티어는 제안 배수 `A=1.5`, `B=1.0`, `C=0.6`을 진단용으로만 보존한다.
활성 `confidence_multiplier`는 모든 티어에서 `1.0`이다.

## 사이징

고정 400,000원 위험예산은 폐기했다. 현재 순수 사이징 함수의 기본값은 다음과
같다.

- 거래당 계획위험: equity 0.5%
- 전체 open heat: equity 2%
- 동일 cluster heat: equity 1%
- slippage 반영 진입가 기준 주문 notional 상한: 300,000원
- 유효 손절거리: `max(구조적 손절거리, ATR × 1.5)`
- Toss 매수·매도 비용과 지정한 양방향 slippage 포함
- 위험·heat·cluster·주문·현금 한도를 모두 만족하는 정수 수량만 반환

`heat` 단위는 원화 계획손실이다. 구조/ATR 손절까지의 원금 손실, Toss 왕복
비용, 양방향 slippage를 합산하며 보유 평가금액(notional)과 구분한다.

100만원 equity에서 기본 1회 위험은 5,000원이다. 1주가 이 한도를 넘거나 기존
open/cluster heat가 소진됐으면 최소 1주로 올리지 않고 0주로 거부한다. 이 함수는
아직 주문 경로에 연결하지 않았다.

## 아직 연결하지 않은 입력

| 규칙 | 현재 상태 | 필요한 것 |
|---|---|---|
| 섹터 대표주 9개 섹터 | 종목 목록 없음 | 섹터별 canonical symbol 설정 |
| 보유종목 합집합 | 기존 cycle에 있음 | 새 유니버스와 결합 |
| 외인/기관 수급 | 순수 PIT 계약만 구현 | 6세션 `available_at`, 순매수, 거래대금 저장 |
| 선행 PER 성장/업종 percentile | 없음 | point-in-time 재무·컨센서스 데이터 |
| 이벤트 직전 | 없음 | 실적·공시·기업행사 달력과 임박 기간 정의 |
| 갭상승 추격 | 임계값 미정 | 전일 종가 대비 시가 gap 기준 |
| 손절선 | 신규 후보에 없음 | setup별 stop 산출 규칙 |
| 자동 regime | 보류 | benchmark 기반 사전 정의와 walk-forward |

누락 입력을 임의의 `false`나 현재값으로 채우면 look-ahead 또는 안전 필터 우회가
생긴다. 실제 scanner/백테스트 연결은 위 데이터 계약과 임계값을 정한 뒤 한다.

## 현재 결정

- pure evaluator, PIT 수급 집계, 정수 사이징과 회귀 테스트만 추가
- 기존 dynamic ranking universe와 주문 경로 변경 없음
- 기존 MA 전략, daily/open/risk notional 값 변경 없음
- 실제 200일 캔들·수급·point-in-time 밸류 데이터 백테스트 전 성과 주장 없음

## 협업 검증 결과

- Codex: 구현, 경계 테스트, 전체 회귀 검증
- Cursor: 코드·PIT·사이징 리뷰. 중간 세션의 `available_at` 미충족으로 eligible
  창에 구멍이 생기는 경계를 발견
- agy: 시장/PIT 가설 리뷰. look-ahead 차단, 6세션 전환, pooled 정규화,
  미검증 성과 주장 배제를 확인
- 반영: 전체 입력뿐 아니라 최종 eligible 6세션도 `session_index` 연속성을
  다시 검사하고, 중간 미가용 세션 회귀 테스트 추가
- 최종: 전용 20개 및 전체 231개 테스트 통과. Cursor·agy blocker 0
